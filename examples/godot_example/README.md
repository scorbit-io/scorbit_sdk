# Scorbit Godot example

A minimal Godot 4 game that plays one three-ball game against the Scorbit staging environment.

1. Build the add-on (see `wrappers/godot/README.md`).
2. Copy `build/godot/addons/scorbit` into this folder as `addons/scorbit`.
3. Open the project in Godot 4.3 or later and run it. The output shows the pairing link and the
   players as they claim.

The provider, machine id and key in `main.gd` are the staging test values the other examples use.
Use your own from Scorbit support.
